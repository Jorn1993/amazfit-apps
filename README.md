# Amazfit apps

Independent Zepp OS mini-programs for Amazfit watches.

## Buienradar — Balance 2

Rain forecast for the next two hours with a 24-bar timeline, user-selectable city, optional on-demand watch GPS, and forecast auto-refresh every five minutes while open.

- [Source and installation guide](apps/buienradar/README.md)
- [Automatic build workflow](.github/workflows/buienradar.yml)
- [Installation QR](apps/buienradar/public/install-qr.png) (generated by CI)
